# 大画板浏览器实测

12 个独立场景全部通过。在 100,000 个可编辑对象的画板上，以打开时的 5% 缩放平移，帧间隔 P95 从 333.35 ms 降到 16.75 ms。相同手势的输入到第二次动画帧延迟 P95 从 832.6 ms 降到 34.8 ms。刷新后原始对象的 SHA-256 一致，两台浏览器读到相同的新增笔迹，包括全部 16 个输入采样和对应的压感、倾斜值。

## 规模对照

时间单位为毫秒，每格按“基线 → 优化版”排列。首屏就绪从导航计时到画布就绪后的第二次动画帧，另用截图核对可见像素。5 万和 10 万级别采用基线、优化版、优化版、基线的顺序。表中汇报每个版本两次运行的中位数，帧指标先在每次手势中计算 P95。较小规模各测一次。

## 十万对象的其他观测

| 指标 | 基线 | 优化版 |
| --- | ---: | ---: |
| 整板平移错过 60 Hz 刷新间隔占比 | 87.75% | 0% |
| 100% 附近缩放帧间隔 P95 | 16.75 ms | 16.75 ms |
| 真实笔移动至第二次动画帧 | 33.10 ms | 17.05 ms |
| 落笔至保存操作 HTTP 响应结束 | 563.05 ms | 381.80 ms |
| 首次打开时画板 HTTP 响应体 | 23,646,417 字节 | 2,530,507–2,530,508 字节 |
| 测试进程树峰值 RSS 总和 | 2,788 MiB | 2,099 MiB |

十万对象的两次优化版整板平移测试分别得到 16.7 ms 和 16.8 ms 的 P95。手势结束后的 500 ms 内，两次运行的最大帧间隔分别为 33.3 ms 和 16.8 ms。进程树 RSS 包含 Bun 服务、驱动程序和浏览器子进程，共享内存页可能被计入多次。

测试使用本机回环网络、全新 SQLite 数据库、独立 Chromium 用户上下文及固定视口。四个规模的 100% 局部视图采样像素摘要在两个版本间一致。物理触控笔及异地网络的表现需在对应设备和网络上测量。逐帧数据、浏览器版本、构建摘要、视口、画面和数据完整性核验、资源上限见同目录的原始 JSON。
