# 参考界面验收

参考图为 2048 × 1548 像素的 iPad 截图。以原图坐标 (24, 56) 到 (2024, 1488) 的应用区域为基准，浏览器使用 1000 × 716 CSS 像素和 DPR 2。设备外框、系统状态栏、Home 指示条及画板中的文档内容不计入 UI 综合分。

| 指标 | 权重 | 计算对象 |
| --- | --- | --- |
| 控件组位置及尺寸 | 30% | 返回、创建工具、总览、操作、创建画板、笔盒、场景工具、视图工具的矩形交并比 |
| 功能图标与笔具轮廓 | 50% | 31 处前景掩膜，允许 1.5 CSS 像素轮廓偏差。按功能分组平均，空白区域不计匹配 |
| 颜色 | 15% | 5 个实色色井的 RGB |
| 点阵纸 | 5% | 在空白样本中测量点的水平、垂直间距及亮度 |

总分需要达到 95%，同时各组几何误差与前景得分须达到脚本的独立阈值。最终测量文件为 `evidence/reference-ui.json`，浏览器截图为 `evidence/reference-studio.png`，并排对照为 `evidence/reference-comparison.png`。浅色首支笔具的轮廓差异最大。

点击左上角画板菜单中的 **打开示例画板**，可以重现同一视角。示例的 125 个对象包括 47 个文本、33 个矢量色块、33 条线段、12 个箭头。双击 “Hardware Agent” 后可以编辑其内容。由用户提供的原截图没有用作画板背景。

重新运行 `python qa/run.py reference_ui` 会使用包内的参考掩膜；若设置环境变量 `FOLIO_REFERENCE_IMAGE` 指向用户提供的原 PNG，则还会生成新的并排对照图。
