# 画板 Chat

打开画板右下角的对话按钮，选择右上角的模型设置。桌面端左侧显示画布，右侧显示对话。窄屏设备的面板从底部打开。输入消息后按 Enter 发送，Shift+Enter 换行。点击停止可以中断生成。关掉面板或离开画板会中止当前回合。之前已经提交的画布编辑可以在画板上撤销。

## 连接模型

| 选项 | 配置 |
| --- | --- |
| OpenAI / 兼容服务 | 填写提供方公布的模型 ID 和 Chat Completions 基础 URL，如 `https://api.openai.com/v1`。Folio 追加 `/chat/completions` |
| Anthropic | 填写模型 ID 和 Messages 服务的基础 URL，如 `https://api.anthropic.com`。Folio 追加 `/v1/messages` |
| API Key | 在当前标签页输入对应服务的密钥。切换服务地址或刷新后需要重新输入 |

选用模型需支持流式输出、函数调用和工具结果回传。密钥随本次请求交给自托管 Folio 服务，再由服务用于所选提供方的认证。请通过 HTTPS 使用远程实例。浏览器仅在当前标签页内存保留密钥。模型、协议和地址保存在该浏览器当前工作区的本地配置中。模型服务会收到对话上下文，以及它读取的画板内容。

默认可连接公网 HTTPS 服务。内网、回环和 HTTP 服务需要部署者设置 `FOLIO_AI_ALLOWED_ORIGINS`，值为逗号分隔的完整源，含协议和非默认端口，不带路径，例如 `http://127.0.0.1:8080`。容器内的回环地址指向容器本身。转发代理需要关闭 Chat 路由的响应缓冲，并允许长连接。

## 画布操作

| MCP 工具 | 效果 |
| --- | --- |
| canvas_read | 查看视野、选区、对象坐标与文字，可按条件筛选或分页 |
| canvas_create | 批量添加几何图形、文字、便签、表格、连接线、贝塞尔路径和带压力、倾角的笔迹 |
| canvas_update | 按真实对象 ID 改文字、位置、旋转、颜色和可调整的尺寸 |
| canvas_delete | 删除指定对象 |
| canvas_select | 在发起 Chat 的浏览器选择对象 |
| canvas_view | 居中、缩放、适配当前画面或选区 |

Peri 的原生 Agent 运行在 Folio 的 Bun 服务内。每轮使用官方 SDK 的 ChatManager、WASM 和独立的内存 SQLite 会话。Peri 通过 ACP 将原始 MCP JSON-RPC 帧反向送往发起对话的标签页。浏览器里的 MCP Server 使用当前 Quickdraw 编辑器读取或写入，再向 Peri 返回结果。每次工具批量写入形成一个撤销步骤，并走已有的对象提交和跨设备同步流程。视角和选区留在发起设备。

个人聊天记录以工作区身份和画板 ID 隔离。配对设备能读取同一份已完成对话，共享画板的其他协作者保有各自的聊天记录。只读用户可以询问画板内容。每张画板每个身份保留最近 40 轮完整问答。发给模型的历史最多为先前 12 轮，另有上下文字符上限。正在执行的工具和本轮进度属于当前标签页。工具已经确认的画板更改会独立保存，即使用户随后停止本轮对话。

## 验收

`qa/chat.py` 在两个独立浏览器上下文中，用可重复的协议端点检查工具回传、跨设备更新、授权、取消、模型错误及密钥处理。`qa/chat_luna.py` 使用独立的真实 Luna Agent 作为模型端，从空白画板发送画图请求并录制 Chromium。两项测试分别生成回执。真实 Luna 录屏、可编辑画板和验收记录位于交付包的 `evidence/` 目录。
